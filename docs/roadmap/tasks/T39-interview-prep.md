# T39: Interview prep from the version that was sent

**Phase:** 7 · **Depends on:** T16, T23 · **Size:** M

## Goal

Deliberately last (it's closest to a commodity since users can paste into ChatGPT), but cheap to add once the data exists, because the app already knows the exact bullets sent and the JD snapshot.

## Scope

- "Prepare for interview" on application detail: likely questions per selected bullet ("You wrote you reduced load time by 40%, so how did you measure it?"), requirement-based technical topics, gaps they may probe (from T26), company/role recap.
- Uses only the sent version + JD analysis as context; output is prep material, never resume text.
- Saved per application; checklist of practiced items.
- Optional: export to a chat (copy prompt with full context) for users who prefer their own assistant.

## Out of scope

Mock interview voice/video.

## Decisions (resolve in Plan mode)

- Pro-only vs. limited free usage.

## Acceptance criteria

- Questions reference actual bullets from the sent version.
